
# Phase 01: Active Directory & Help Desk

**Days:** 01–20  
**Environment:** Windows Server 2022, Windows 11, Active Directory Domain Services, DNS, and Proxmox VE  
**Domain:** `corp.local`

## Overview

This phase focuses on building practical Active Directory administration, identity management, Windows domain support, and Help Desk troubleshooting skills in my home lab.

I will document actual configurations, verified results, troubleshooting activities, and supporting evidence throughout the phase.

## Learning Objectives

- Inspect and validate Active Directory infrastructure.
- Manage organizational units, users, computers, and security groups.
- Practice account provisioning, password resets, and account troubleshooting.
- Validate domain membership, authentication, and DNS functionality.
- Configure and investigate Group Policy behavior.
- Apply group-based access controls and NTFS permissions.
- Troubleshoot realistic Help Desk scenarios.
- Complete the Day 20 practical capstone.
